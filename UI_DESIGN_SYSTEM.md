# Weather App - Minimalistic Dark UI Design System

## 🎨 Design Philosophy

A sophisticated dark minimalistic interface that's **elegant, accessible, and engaging** without being generic.

### Color Palette

**Primary Background:**
- Base: `#0f0f1e` (Deep charcoal - almost black with slight blue tone)
- Surface: `#1a1a2e` (Elevated surfaces)
- Card: `#16213e` (Card backgrounds with more depth)

**Accent Colors:**
- Primary: `#06d6d0` (Soft cyan - vibrant but calm)
- Secondary: `#118ab2` (Deeper blue)
- Success: `#06d6d0`
- Warning: `#ffa500` (Muted orange)
- Danger: `#ef476f` (Soft red)

**Text:**
- Primary: `#f0f3f7` (Off-white, easy on eyes)
- Secondary: `#a8b2d1` (Muted for hints)
- Muted: `#7a859b` (For disabled states)

**Borders & Dividers:**
- `rgba(6, 214, 208, 0.1)` (Subtle cyan accent lines)
- `rgba(255, 255, 255, 0.05)` (Almost invisible separators)

### Typography

- **Font Family:** `Inter` (modern, clean)
- **Headings:** 600-700 weight
- **Body:** 400-500 weight
- **Size Scale:** xs(12px) → sm(14px) → base(16px) → lg(18px) → xl(24px) → 2xl(32px)

### Spacing System

`4px`, `8px`, `12px`, `16px`, `24px`, `32px`, `48px` (4px base)

### Border Radius

- Small buttons/inputs: `6px`
- Cards: `12px`
- Large elements: `16px`

### Shadows

- **Subtle:** `0 2px 8px rgba(0, 0, 0, 0.3)`
- **Medium:** `0 8px 24px rgba(0, 0, 0, 0.4)`
- **Focus:** `0 0 0 3px rgba(6, 214, 208, 0.2)` (cyan glow)

## 🏗️ Component Structure

### Layout
- Header: Minimal, fixed with subtle border
- Hero/Search: Large input field with smooth animations
- Cards: Clean grid with hover effects
- Buttons: Rounded with state indicators

### Micro-interactions
- Smooth transitions on hover (200ms)
- Subtle scale effects on buttons (102%)
- Input focus: Cyan glow outline
- Loading: Gentle pulse animation

## 📱 Responsive Design

- Mobile: Stacked layout, full-width cards
- Tablet: 2-column grid
- Desktop: 3-column with sidebar option

## ♿ Accessibility

- Contrast ratio: 7:1+ for WCAG AA
- Focus indicators visible with cyan outline
- Semantic HTML structure
- ARIA labels for interactive elements

---

This design maintains professional aesthetic while being **intentionally dark but not oppressive**, with cyan accents that feel modern without being overwhelming.
